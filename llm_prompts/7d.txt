    def get_unlabeled_page(self, *, has_note=None, cursor=None, limit=50,
                           latest_first=True):
        """Get an ordered page of unlabeled base records (keyset pagination).

        Returns a DataFrame with the same columns as get_results_page
        (one row per record, results columns NULL when the record has no
        results row, ``tags`` parsed), ordered by record_id.
        ``cursor`` is ``(None, record_id)`` of the last row of the previous
        page (time is always NULL for these rows).
        """
  SQL shape (select EVERY results column explicitly, taking record_id from
  the record table):
      SELECT rec.record_id AS record_id, r.label, r.classifier, ... all
             other results columns ...
      FROM {self.record_table_name} AS rec
      LEFT JOIN results AS r ON r.record_id = rec.record_id
      WHERE rec.duplicate_of IS NULL AND r.label IS NULL
        [AND r.note IS NOT NULL | AND r.note IS NULL]       -- has_note
        [AND rec.record_id < :cid | > :cid]                 -- cursor
      ORDER BY rec.record_id DESC|ASC
      LIMIT :limit
  Use pd.read_sql_query with dtype=RESULTS_TABLE_COLUMNS_PANDAS_DTYPES and
  attach tags exactly like get_results_page does.
