WHY
  In the Collection page (LabeledRecord.js) an invalidated infinite query
  refetches every loaded page. react-query 3.39.3 computes each page's
  param with getNextPageParam and stops only on `undefined`. Our function
  returns `false` when there is no next page, so after the list has
  shrunk the client requests `/labeled?...&cursor=false`. The server
  cannot base64-decode "false", answers 400, and the whole list shows an
  error.
  Separately, test_list_item_cleaning expects list items containing "," or
  ";" to be dropped. The user decided (2026-10-19) that they ARE allowed.
  The code is right and the test is outdated.

FACTS (verified — trust these)
  - asreview/webapp/src/ProjectComponents/HistoryComponents/LabeledRecord.js
    has, inside useInfiniteQuery's options:
        getNextPageParam: (lastPage) => lastPage.next_cursor ?? false,
  - `undefined` from getNextPageParam means "no next page" in react-query
    v3, so hasNextPage stays correct.
  - The frontend is a CRA app with a jsconfig baseUrl of "src". Jest runs via
    `react-scripts test` and needs no new dependency (verified: a trivial
    test passes). Today the only test is the CRA stub src/App.test.js.
  - asreview/webapp/tests/test_api/test_llm_mapping.py::test_list_item_cleaning
    (around line 257) asserts:
        assert "bad,comma" not in names
        assert "bad;semicolon" not in names
        assert "comma" in caplog.text or "',' or ';'" in caplog.text
    asreview/webapp/_api/llm_mapping.py keeps such items and logs no
    comma warning. Do NOT change llm_mapping.py.

PART A — labeledPaging.js (new file)
------------------------------------------------------------------------
    // Pure helpers for the Collection list (no React, no network).

    /**
     * Next-page param for react-query's useInfiniteQuery.
     *
     * Must return `undefined` (not `false` or `null`) when there is no next
     * page: react-query v3 refetches every loaded page on invalidation and
     * only stops at `undefined`; anything else is sent as `cursor=...`.
     */
    export const getNextPageParam = (lastPage) =>
      lastPage?.next_cursor ?? undefined;

  In LabeledRecord.js import it
      import { getNextPageParam } from "./labeledPaging";
  and use `getNextPageParam,` in the useInfiniteQuery options instead of
  the inline arrow function.
