DESIGN (decided — follow it)
  A. ProjectAPI.js: four static methods, each resolving result.data:

       fetchLabeledChanges({project_id, subset, filter, since, boundary})
       fetchLabeledIds({project_id, subset, filter, boundary})
       fetchRecordsByIds({project_id, ids})       // ids.join(",")

  B. collectionModel.js: add

  C. New hook src/ProjectComponents/HistoryComponents/useCollection.js
       export const POLL_MS = 15000;
       export const PATCH_CHUNK = 200;
       export default function useCollection({project_id, subset, filter})
         returns {state, isLoading, error, loadMore, refresh,
                  onRowUpdated, onEditingChange}
     Internals:
     - stateRef + useState: commit(next) sets both. Async code always
       reads stateRef.current at the moment it applies a result.
     - snapshotKey = JSON.stringify([project_id, subset, filter]). On
       change (and on mount): gen.current += 1, commit(emptyState(subset)),
       load the first page. Every async step captures `g = gen.current`
       and drops its result if gen.current !== g. Navigating away
       unmounts the hook, and F5 starts empty: no cache (spec default).
     - One operation at a time: busy ref. loadMore, poll, patch and
       refresh each run with busy = true. A poll tick while busy is
       skipped (the next tick retries). loadMore while busy sets
       wantMore = true and runs as soon as the current operation ends.
     - loadMore: if !hasMore return. fetchLabeledPage with cursor =
       (boundary is a cursor string ? boundary : undefined), per_page 50
       → appendPage.
     - poll: skipped if document.hidden, busy, or nothing is loaded yet.
       fetchLabeledChanges({since: state.watermark, boundary:
       snapshotParams(state).boundary}) → markChanges.
         if the response is a reset or has ≥ 1 change:
           queryClient.invalidateQueries(["fetchLabeledStats", {project_id}])
         idsToPatch → fetchRecordsByIds in chunks of PATCH_CHUNK →
           applyRowUpdates(rows, users)
         configChanged → fetchLabeledPage({per_page: 1}) → applyForms
           (forms and users only; its rows are ignored)
       Timer: setInterval(poll, POLL_MS) in an effect bound to
       snapshotKey. A visibilitychange listener calls poll() at once
       when the tab becomes visible. Clean both up.
     - refresh: fetchLabeledIds({boundary}) → reconcile(state, resp,
       [...dirtyIds]) → fetch idsToFetch in chunks → applyRowUpdates;
       configChanged → applyForms as above. Also invalidate the stats.
     - onRowUpdated(row): commit(applyRowUpdates(stateRef.current,
       [row])) and invalidate the stats (D13: no other special handling).
     - onEditingChange(record_id, editing): add to / remove from a
       dirtyIds Set ref.
     - Errors: keep the last good state; expose `error` (the latest
       failure message) and clear it on the next success. A failed poll
       does not show anything (the next tick retries). A failed
       loadMore or refresh sets error.

  F. RecordCardLabeler.js: new optional prop onEditingChange = null.
       const editing = isDirty || showNotesDialog || showTagsDialog ||
                       showListsDialog;
       const editingCb = React.useRef(onEditingChange);
       editingCb.current = onEditingChange;
       React.useEffect(() => {
         if (editingCb.current) editingCb.current(editing);
       }, [editing]);
       React.useEffect(() => () => {
         if (editingCb.current) editingCb.current(false);
       }, []);
     (The ref keeps the effect from firing on every render, because the
     card creates a new arrow function each time.)
