WHY
  The Collection shows a snapshot (everything loaded so far, D3). The
  client needs three cheap questions answered:
    - "What changed since version V, and does each changed record belong
      in my view at or before my boundary?" → labeled/changes (polled
      every 15 s)
    - "Give me these rows in /labeled shape" → records?ids=
    - "What is the full ordered membership down to my boundary?" →
      labeled/ids (Refresh = reconcile, D4)
  All three MUST filter and order exactly like /labeled. That is why 10b
  extracted _parse_labeled_query and _iter_labeled_matches: reuse them,
  never copy them.

DESIGN (decided — follow it)
  Database (database.py), next to get_project_state:
    def get_changes_since(self, since, until):
        """[(record_id, version)] for change_log rows with
        since < version <= until: one entry per record (its max version),
        ordered by that version."""
        SELECT record_id, MAX(version) AS v FROM change_log
         WHERE version > ? AND version <= ?
         GROUP BY record_id ORDER BY v
    def count_changed_records_since(self, since, until):  (optional; you
        may instead fetch with LIMIT 201 and test the length)
    def prune_change_log(self, older_than_s=7*86400, min_interval_s=3600,
                         now=None):
        """Delete change_log rows older than `older_than_s`, at most once
        per `min_interval_s`. Records the highest deleted version in
        project_state.pruned_version. Returns the number of rows deleted."""
        In one transaction:
          read last_pruned_at; if it is not None and now - last_pruned_at
          < min_interval_s → return 0
          cutoff = now - older_than_s
          SELECT MAX(version) FROM change_log WHERE changed_at < cutoff
          DELETE FROM change_log WHERE changed_at < cutoff
          UPDATE project_state SET last_pruned_at = now,
                 pruned_version = MAX(pruned_version, COALESCE(:maxdel, 0))
          commit
    def get_record_states(self, record_ids):
        """Results state for arbitrary base records, in the same columns as
        get_unlabeled_page (record LEFT JOIN results, NULLs when there is
        no results row), with ``tags`` parsed. Order follows record_ids;
        unknown ids are skipped. No filter, no duplicate_of condition."""
        Reuse get_unlabeled_page's results_columns list: move it to a
        module-level constant _PAGE_RESULTS_COLUMNS and use it in both
        places. Chunk the IN list at 900.

  projects.py helpers (after _iter_labeled_matches):
    def _sort_tuple(q, key):
        """Total-order tuple of a (time, record_id) key in display order;
        smaller sorts first."""
        t, rid = key
        if q["subset"] == "unlabeled":
            return (-rid,) if q["latest_first"] else (rid,)
        if q["latest_first"]:
            return (t is None, -(t or 0.0), -rid)
        return (t is None, t or 0.0, rid)
    def _parse_boundary(q):
        """request.args["boundary"]: "end" → None (no limit); otherwise a
        cursor → its decoded key. Missing or invalid → ValueError."""
    def _scan_to_boundary(db, q, boundary_key):
        """Return (matches, has_more): every (state, key) at or before the
        boundary (all when boundary_key is None) and whether at least one
        match exists beyond it."""
        Iterate _iter_labeled_matches(db, q, None, 500). Stop at the first
        key whose _sort_tuple > _sort_tuple(boundary_key), and report
        has_more=True in that case.
    def _sort_key_json(q, key):
        rid for unlabeled; [time, rid] for labeled (time may be None)

  1. GET /projects/<project_id>/labeled/changes?since=<int>&boundary=…
       since missing / not an int / < 0 → 400.
       boundary invalid → 400 (spec: cursor errors stay 400).
       with project.db as db:
         db.prune_change_log()                 # opportunistic, ≤ 1/hour
         ps = db.get_project_state()           # the watermark, read FIRST (D11)
         wm = ps["version"]
         if since > wm or since < ps["pruned_version"]:
             return {"reset": True, "watermark": wm}
         changes = db.get_changes_since(since, wm)
         if len(changes) > 200:
             return {"reset": True, "watermark": wm}
         out = []
         if changes:
             matches, _ = _scan_to_boundary(db, q, boundary_key)
             keys = {int(s["record_id"]): k for s, k in matches}
             for rid, v in changes:
                 in_view = rid in keys
                 out.append({"record_id": rid, "version": v,
                             "in_view": in_view,
                             "sort_key": _sort_key_json(q, keys[rid])
                                         if in_view else None})
       return {"watermark": wm, "config_version": ps["config_version"],
               "changes": out}
     The membership scan only runs when there ARE changes (most polls are
     empty and cost two small SELECTs).
     sort_key is null when in_view is false (the client does not need
     it then; flagged in the spec notes).

  2. GET /projects/<project_id>/records?ids=1,2,3
       Parse the comma-separated ints. Empty → result []. More than 500

         states = [row for _, row in db.get_record_states(ids).iterrows()]

     Check that each state passed to _build_rows looks exactly like an

  3. GET /projects/<project_id>/labeled/ids?boundary=…
       with project.db as db:
         ps = db.get_project_state()          # first (D11)
         matches, has_more = _scan_to_boundary(db, q, boundary_key)
         ids = [int(s["record_id"]) for s, _ in matches]
         versions = db.get_record_versions(ids)
         items = [[rid, int(versions.get(rid, 0)), _sort_key_json(q, k)]
                  for (s, k), rid in zip(matches, ids)]
         if not has_more:
             next_cursor = None
         elif matches:
             next_cursor = _encode_cursor(*matches[-1][1], q["filter_sig"])
         else:
             # Every loaded row left the view, but matches exist beyond the
             # old boundary: hand the boundary back so scrolling resumes there.
             next_cursor = request.args["boundary"]
       return {"watermark": ps["version"],
               "config_version": ps["config_version"],
               "items": items, "next_cursor": next_cursor}
     next_cursor lets the client keep scrolling from its (possibly
     shifted) boundary with the normal /labeled?cursor=. It is null
     exactly when nothing matches beyond the boundary.
