PART A — DAO method (asreview/database/database.py, near reassign_stale)

      def touch_last_active(self, record_id, user_id):
          """Bump last_active for a user's pending checkout of a record.

          Returns True if the record is still checked out to this user (a
          pending results row with label IS NULL and matching user_id existed
          and was updated); otherwise False.
          """
          now = time.time()
          con = self._conn
          cur = con.cursor()
          row = cur.execute(
              "UPDATE results SET last_active = ? "
              "WHERE record_id = ? AND user_id = ? AND label IS NULL "
              "RETURNING record_id",
              (now, record_id, user_id),
          ).fetchone()
          con.commit()
          return row is not None

  Add DAO tests to tests/test_llm_db.py:
    1. Fresh checkout: after checkout_oldest_dispatched(user_id=1), a backdated

    2. Wrong user: touch_last_active(record_id, 2) returns False and does not

    3. Already labeled: after labeling the record, touch_last_active(record_id,
       1) returns False (no pending row).

PART B — route (asreview/webapp/_api/projects.py)

      @bp.route("/projects/<project_id>/record/<record_id>/heartbeat",
                methods=["POST"])
      @login_required
      @project_authorization
      def api_record_heartbeat(project, record_id):  # noqa: F401
          """Liveness ping for an open record. Returns {"active": bool}."""
          user_id = (
              current_user.id
              if current_app.config.get("AUTHENTICATION", True) else None
          )
          with project.db as db:
              active = db.touch_last_active(int(record_id), user_id)
          return jsonify({"active": active})
