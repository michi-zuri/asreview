INPUT SHAPES (trust these)
  payload : the parsed LLM JSON. EXPECTED shape (from task 0c's contract):
      {
        "labels": [
          {"group": "<group_export>",
           "values": [{"checked": "<option_export>"},
                      {"checked": "<option_export>", "text": "<free text>"}]}
        ],
        "lists": [
          {"list": "<list_name>", "items": ["<string>", ...]}
        ]
      }
    BUT it may be anything (wrong types, missing keys, extra junk). Treat it
    as untrusted.

  tags_form : list[dict] | None  (read_tags_data shape). Each group:
      {"id": group_id, "export": "<group_export>", "single_select": bool,
       "values": [{"id": option_id, "export": "<option_export>",
                   "free_text": bool, ...}], ...}
    This is the AUTHORITATIVE contract: only exports present here are valid,
    and it provides the export->id mapping and free_text/single_select flags.

  lists_form : list[dict] | None  (read_lists_data shape). Each:
      {"id": <list_id>, "name": "<list_name>", ...}
    Authoritative name->list_id mapping.

WHAT TO IMPLEMENT
  Create a NEW file: asreview/webapp/_api/llm_mapping.py
  (Apache license header + numpy-style docstring. Imports: stdlib only —
   `logging`. Do NOT import the database or utils modules.)

  Signature:
      def map_llm_payload_to_asreview(payload, tags_form, lists_form):
          """Map an LLM screening payload to ASReview tag/list structures.

          Returns
          -------
          dict
              {"tags": [...], "lists": [...]} always. On unusable input the
              lists are empty. Never raises.
          """

  OUTPUT shape (exactly this):
      {
        "tags": [
          {"id": <group_id:int>, "values": [
             {"id": <option_id:int>, "checked": True, "text": <str|None>}
          ]}
        ],
        "lists": [
          {"list_id": <list_id>, "name": <item_str>, "sorted_at": <float>}
        ]
      }
    Notes on the output:
      - Only CHECKED options are emitted (checked is always True in output;
        unchecked options are simply absent — matches _save_tags semantics).
      - "text" is None unless the option's contract free_text is True AND the
        payload provided a non-empty string, in which case it is that string.
      - Emit a group only if it has at least one valid checked value.
      - The list items intentionally OMIT item_id (a uuid) and use a numeric
        sorted_at; the persistence caller (a later task) adds item_id via the
        project's uuid7() right before calling replace_lists.

  MAPPING & VALIDATION RULES (all "drop" cases must logging.warning):
    Setup:
      - tags_form/lists_form: treat None as [].
      - Build group_lookup: group_export -> {
            "id": group_id, "single_select": bool,
            "options": {option_export -> {"id": option_id, "free_text": bool}}}
      - Build list_lookup: list_name -> list_id.
    Labels:
      - If payload is not a dict, or payload.get("labels") is not a list:
        produce no tags (do not crash).
      - For each group entry:
          * skip if not a dict, or "group" missing/not a known export (log).
          * gather checked values from entry.get("values"); if not a list, skip.
          * for each value dict (skip non-dicts, or missing "checked"):
              - option export = value["checked"]; must exist in this group's
                options, else drop+log.
              - dedupe by option_id within the group (keep first; log dupes).
              - text: if option free_text is True and value.get("text") is a
                non-empty string -> use it; else None.
          * single_select enforcement: if the group is single_select and more
            than one distinct valid option was checked, keep only the FIRST and
            drop the rest (log).
          * emit {"id": group_id, "values": [...]} only if >=1 value remains.
    Lists:
      - If payload.get("lists") is not a list: produce no lists.
      - For each list entry:
          * skip if not a dict, or "list" missing/not a known name (log).
          * items = entry.get("items"); if not a list, skip (log).
          * for each item, in order:
              - coerce to string via str(item).strip(); drop if empty (log).
              - drop if it contains ',' or ';' (replace_lists forbids) (log).
              - dedupe within this list by exact name (keep first).
              - emit {"list_id": list_id, "name": name,
                      "sorted_at": float(<running index within this list>)}
                where the index starts at 0 for each list's first kept item.
      - Two different list containers are independent; a name may repeat across
        different lists.
    General:
      - Never raise. Any unexpected structure -> log and skip that piece.
